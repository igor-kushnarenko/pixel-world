# Проверка прототипа

Дата: **3 ноября 2026**, Windows, Chrome **156.0.8078.80**, WebGL 2 через ANGLE/SwiftShader.

## Результат

- `npm run build` — успешно: проверка TypeScript, production-демо `dist/`, независимый ES-модуль и декларации `lib/`.
- `npm test` — **16 тестов пройдены**.
- `npm run test:browser` — **36 проверок пройдены** после подключения авторского города (первый технический прототип: 26). Браузерных исключений и ошибок шейдеров нет. Машиночитаемый отчёт: `artifacts/browser-report.json`.
- Все пять снимков сцены просмотрены/сохранены: каноническая ночь, облака, гроза, рассвет, узкий экран. Основные настольный и мобильный макеты дополнительно проверены визуально.
- Канонический документ в проекте побайтно совпадает с предоставленным исходником. SHA-256: `34E5F839096C49FAFAE70D9F08BE857477BEBB9989CBCAA50AD2AB08096B89D4`.

## Что проверено реальным framebuffer

| Требование | Проверка |
| --- | --- |
| Канонический старт | 22:00, облака/луна/звёзды/приборы выключены |
| Независимые облачные поля | Дальний и низкий планы поочерёдно включаются и меняют GPU-изображение при продвижении времени |
| Оконная маска | При включении облаков **0 изменённых пикселей** вне проёма, включая раму и перемычки |
| Глубина | Оба стандартных плана скрываются за непрозрачным фасадом; изменение depth низкого плана перемещает его перед фасадом |
| Pixel-perfect вывод | При 2× увеличении каждый логический пиксель образует одинаковый блок 2×2: **0 несовпадений** |
| Стабильность движения | Очень малый шаг времени не меняет кадр; нулевой ветер полностью останавливает облака |
| Пресеты | Экспорт, импорт и одинаковое seek дают побайтно одинаковый GPU-кадр |
| Ошибочный импорт | Отклоняется без изменения текущего состояния |
| Грозовой свет | Вспышка одновременно повышает яркость пикселей неба, явно принимающего фасада и маски подоконника; в обычном режиме запуск запрещён |
| Исходный PNG | Тестовый PNG загружается через TextureLoader; исходный цвет и нативное расположение сохраняются без ресайза |
| Alpha | Прозрачное отверстие PNG показывает точный цвет фона без цветной каймы |
| Несовместимая маска | Неправильный размер отклоняется; после неуспешного создания canvas удаляется |

UI-проверки: переключение окна/панорамы, слайдер, включение облаков из канонического нуля, загрузка JSON-файла, скачивание JSON, узкий экран без растягивания нативных пикселей и без горизонтального скролла всей страницы. Повторный `dispose` безопасен.

## Границы проверки

В первом прототипе городские/комнатные PNG отсутствовали. Затем пользователь предоставил четыре городских слоя, `room.png` и `nightcity.psd`. Город подключён по исходному холсту PSD 1890 × 1063. Его композиция в режиме «По PSD» проверена на CPU и по реальному GPU-кадру: **максимальное отличие каналов RGB от превью PSD равно 0**. Контрольные суммы копий PNG, PSD и подготовленных экспортов совпадают с манифестом.

Добавленные браузерные проверки охватывают исходное разрешение, сравнение с PSD, работу двух облачных полей, переключение процедурного неба, выгрузку всего кадра и доступность большой сцены при прокрутке. Снимки реального города: `artifacts/nightcity-psd.png`, `nightcity-procedural.png`, `nightcity-clouds.png`, `nightcity-app.png`; проверка импорта: `artifacts/psd-import-report.json`.

Комната не размещена в предоставленном PSD и имеет другой размер — 1672 × 941. Её исходник сохранён, но интеграция и световые маски комнаты ещё предстоят. Отдельных emissive masks реального города пока нет; нарисованные в PNG огни сохранены без изменений, соответствующий регулятор отключён. Исходная alpha, включая почти непрозрачные значения 252–254, не исправлялась автоматически.

SwiftShader подтверждает выполнение GLSL и результат композитинга; **целевой FPS на пользовательской видеокарте не измерялся**. При крупном логическом холсте стоимость полноэкранных проходов растёт. В канонической демосцене 9 draw calls включая итоговую копию; включение обоих облачных полей добавляет 2. Готовая библиотека около 25 KiB без внешней Three.js; полный демобандл около 525 KiB (около 140 KiB gzip).

Молнии — художественный сценарий с единичной затухающей вспышкой; сложные направленные тени, объёмное рассеяние, физическая симуляция дождя и произвольные луны в MVP не реализованы. Переход времени выполняется через параметр `timeOfDay`; автоматический цикл часов или переход между целыми пресетами задаётся хостом.

Дробный системный DPI/масштаб браузера может изменить экранное отображение вне контроля WebGL. Основная проверка 2× выполнена при DPR=1, масштабе браузера 100%. При узком экране сцена остаётся нативной и прокручивается внутри области просмотра.
