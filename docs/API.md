# API и модель рендера

## Создание

`await AtmosphereEngine.create({ container, scene, parameters?, onError? })` возвращает готовый движок после загрузки изображений. Ошибка загрузки или несовместимый размер отклоняют Promise; уже созданные ресурсы освобождаются. `container` должен иметь явную высоту; рекомендуется `display:flex; align-items:center; justify-content:center; overflow:auto`.

`scene.width/height` — обязательное логическое разрешение из ассетов, целые значения 1…4096. Прототип не уменьшает его ради производительности. Чрезмерный размер может быть ограничен конкретной GPU. Объекты `ImageLayer` допускают `source` как URL, загруженную `THREE.Texture` или `HTMLCanvasElement`. Метаданные переданной текстуры не изменяются: движок клонирует её и владеет только копией. Не изменяйте пиксельные данные источника во время использования.

## Методы

| Метод | Действие |
| --- | --- |
| `start()` / `stop()` | Включить/приостановить собственный requestAnimationFrame |
| `update(deltaSeconds)` | Продвинуть модель и отрисовать, если временем управляет хост. Не совмещать с `start()` |
| `render()` | Перерисовать текущее состояние без продвижения времени |
| `getParameters()` | Независимая копия параметров |
| `setParameters(patch)` | Проверить и атомарно применить глубокое частичное обновление |
| `applyPreset(name)` | Полностью заменить настройки именованным пресетом и сбросить время/ветер |
| `exportPreset()` | Полный JSON настроек v1 |
| `importPreset(json)` | Валидировать и полностью восстановить настройки, сбросить время/ветер |
| `seek(seconds)` | Детерминированно задать возраст облаков при **текущих** настройках ветра; сбросить события молний |
| `triggerLightning()` | Однократная вспышка при включённом storm; возвращает `false`, если режим выключен или действует защита повторного запуска |
| `setLayerVisible(id, visible)` | Независимо выключить любой проход, PNG или маску света |
| `setWindowMaskEnabled(bool)` | Включить/выключить оконное ограничение внешних слоёв для редактора панорамы |
| `resize()` | Пересчитать целый CSS-масштаб; обычно вызывается ResizeObserver автоматически |
| `getDiagnostics()` | Разрешение, масштаб, время, число draw calls, отсортированные проходы |
| `readPixels()` | Синхронно прочитать RGBA8 framebuffer; начало снизу слева. Только для проверок/экспорта, не каждый кадр |
| `dispose()` | Остановить цикл, отключить наблюдатели и события, освободить GPU и убрать canvas; повторный вызов безопасен |

Внешняя пауза замораживает время; редактирование настроек на паузе сразу перерисовывает сцену. При собственной анимации dt ограничен 0.1 секунды, чтобы возврат из скрытой вкладки не вызывал скачок погоды. При потере WebGL-контекста движок останавливается, вызывает `onError`; восстановление контекста возобновляет предыдущий режим.

`seek()` не воспроизводит историю редактирования ветра и автоматических грозовых событий. Для одинаковых параметров и одинакового `seek(t)` облака и палитра воспроизводимы побайтно. Экспорт сохраняет **настройки**, а не текущую фазу анимации.

## Контракт параметров

Полный JSON доступен кнопкой «Сохранить JSON». Минимальная схема из канона поддерживается без расширенных полей; отсутствующие поля получают канонические значения.

| Путь | Диапазон / значения |
| --- | --- |
| `presetVersion` | Только `1` |
| `seed` | Целое 0…65535, исходное 712 |
| `timeOfDay` | 0…24; 24 совпадает с 0 |
| `sky.palette` | `cyberpunk_night`, `coastal`, `forest`; время суток действует во всех палитрах |
| `sky.starsEnabled` | Boolean; `false` на старте, интенсивность уменьшается днём, облака рисуются поверх звёзд |
| `sky.moonEnabled` | Только `false`; луна не реализована |
| `sky.horizonGlow` | 0…1 |
| `clouds.enabled` | Boolean; `false` на старте |
| `clouds.coverage / density / windSpeed` | 0…1 |
| `clouds.scale` | 0.25…4; большее значение даёт более мелкую структуру шума |
| `clouds.windDirectionDeg` | −360…360; 0 — вправо, 90 — вниз по экрану |
| `clouds.layers.far / low` | Независимые параметры, таблица ниже |
| `weather.fog / rain` | 0…1 |
| `weather.stormEnabled` | Boolean; разрешает автоматические и ручные вспышки |
| `lighting.cityLightsIntensity / exteriorRoomFill` | 0…1, нормализованные художественные значения |
| `lighting.interiorLightsEnabled / radioBacklightEnabled / computerEnabled` | Boolean, по умолчанию `false` |
| `render.sampling / pixelGrid` | Только `nearest` / `match_scene_assets` |
| `render.dithering` | Boolean, по умолчанию `false`; применяется к ступеням неба |
| `render.colorSteps` | Целое 2…32, исходное 12; пространственные ступени градиента |

Поля `clouds.layers.far` и `clouds.layers.low`:

| Поле | Значение |
| --- | --- |
| `enabled` | Boolean |
| `depth` | 1…999, больше — ближе |
| `coverage / density` | 0…1; множители глобальных значений |
| `scale` | 0.25…4; множитель масштаба шума |
| `height` | 0…1 от верхнего края сцены до центра полосы |
| `thickness` | 0…1; 0 скрывает облачную полосу |
| `speed` | 0…4, множитель общей скорости ветра |
| `colorSteps` | Целое 2…16; ступени тона и прозрачности облаков |

Ветер 1 соответствует 12 логическим пикселям в секунду для `speed=1`. Внутренняя позиция непрерывная, шейдер округляет её до ближайшего целого пикселя. Изменение скорости не пересчитывает уже пройденный путь; `seek` намеренно пересчитывает путь с начала при текущей скорости.

`canonical`, `drifting`, `storm`, `dawn`, `day` — встроенные пресеты. Переход времени плавно интерполирует художественные цвета между опорными часами, затем шейдер квантует вертикальный градиент. Самопроизвольное течение часов не включено: задавайте `timeOfDay` из сценария хоста.

Неизвестные поля, несовместимая версия, `NaN`, `Infinity`, значения вне диапазона и попытки включить bilinear/луну отклоняются. Ошибочный импорт сохраняет предыдущие настройки. Ограничение JSON — 64 KiB.

## Свет и порядок

`LightMask` имеет `id, source, depth, scope, group, color`, опциональные `intensity` (0…1) и `pulse: { amount, periodSeconds }`. Цвет задаётся `#rrggbb`. Маска обязана совпадать с логическим размером всей сцены. Канал R × alpha определяет принимающую поверхность, а не автоматически определяемые окна/объекты.

Группы `cityWindows`, `neon`, `street`, `reflections` следуют `cityLightsIntensity`; `exteriorRoom` — внешнему свету, цвету неба, времени суток и молнии; `interior/radio/computer` — своим переключателям. Группы без масок ничего не рисуют. Пульсация возможна только при явно заданном `pulse`; в демонстрации она отсутствует.

Каждый PNG получает явный `depth` (0 < depth < 1000), `scope: world|room`, необязательные целые `x/y` и `opacity`. По умолчанию размер берётся из файла без изменений. Опциональный `placement: {x,y,scale}` задаёт **явный авторский** масштаб и смещение центра слоя; позиция привязывается к целому логическому пикселю, nearest-сэмплинг сохраняется. Значения масштаба — 0.1…4. Неявного подгона нет. `receivesLightning: true` разрешает модуляцию непрозрачных пикселей конкретного слоя; по умолчанию выключено.

Расширения v0.2: `cityLightMask` — подготовленная RGB-маска окон/неона, совпадающая с исходным PNG и его трансформом; `roomLights` — карты света left/right/emitters и явные координаты шкалы/LED радио; `tint` — художественная цветовая модуляция. Методы `setLayerPlacement`, `setLayerTint`, `setRoomLightLevels(id,left,right,radio)` управляют ими без изменения изображений. `autoRender:false` в опциях позволяет объединять изменения и вызывать один `update(dt)` за кадр. `onLightning` сообщает о том же событии вспышки, что использует GPU, для синхронизации грома.

Ортографическая камера и `renderOrder` реализуют painter's algorithm: большое значение рисуется позже. Аппаратный depth test выключен, чтобы прозрачные полноэкранные проходы не перекрывали друг друга невидимыми пикселями. Глубину occlusion обеспечивают PNG alpha, порядок и отдельные маски. Для одинаковой глубины действует порядок добавления; используйте разные глубины, если перекрытие существенно.

## Пиксели и цвет

Рендер идёт в RGBA8 render target с исходным логическим разрешением, без depth/MSAA/mipmaps. Финальный проход копирует его без фильтров. Canvas имеет такое же физическое разрешение и `image-rendering: pixelated`; CSS-размер — целое кратное. Если экран меньше сцены, масштаб остаётся 1, просмотр прокручивается внутри контейнера. Letterbox занимает оставшееся место при достаточном размере. Для проверки 1:1 используйте масштаб браузера 100%; дробный DPI/zoom ОС может влиять на окончательный вывод браузера.

Это стандартное поведение библиотеки и мастерской. Пользовательская квартира переопределяет только CSS-показ: вписывает весь нативный framebuffer в экран с `image-rendering: pixelated` и полями, как референс `nightcity`. При недостаточном размере экрана fit дробный; одинаковый размер каждого физического пикселя в таком режиме не гарантируется. Сам framebuffer и PNG сохраняют исходное разрешение.

Сцена композитится в авторском display-space цвете: встроенные преобразования цвета и tone mapping Three.js отключены для пользовательских шейдеров. Это художественная 2D-композиция, не физически корректная линейная HDR-система. Alpha входных PNG — straight, `premultiplyAlpha=false`; RGB полностью прозрачных пикселей не влияет на результат при nearest.
