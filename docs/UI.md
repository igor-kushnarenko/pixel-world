# Интерфейс панорамы · 04.11.2026

## Изученные примеры

- [Noisli — Features](https://www.noisli.com/features): независимая громкость фоновых звуков, сочетания звуков и инструменты для спокойной работы. Для нашей сцены применены отдельные регуляторы общей громкости и радио в одном разделе.
- [Apple — Background Sounds](https://support.apple.com/en-lb/109346): быстрый доступ к включению фонового звука и громкости. Для сцены основные задачи доступны через постоянную компактную панель.
- [Lofi — официальный FAQ Discord](https://support-apps.discord.com/hc/en-us/articles/26502210208663-Lofi-FAQ): сцена, музыка и настраиваемые эффекты окружения. Сохранены управление предметами прямо в квартире и отдельные настройки окружения.

Это обзор официальных описаний продуктов, а не измерительное исследование их пользователей. Решения ниже — адаптация к нашей многослойной сцене; чужие интерфейсы и графика не копировались.

## Реализация

Вместо единого длинного меню используется нижняя панель задач: Сцена, Звук, Свет, Детали и полный экран. Открыт только один раздел. Панель остаётся компактной и приглушается при бездействии; наведение и клавиатурный фокус возвращают её видимость.

- **Сцена:** предыдущий/следующий вид, время суток, облака и дождь, сила дождя.
- **Звук:** общий mute и громкость, радио, станция и громкость радио.
- **Свет:** два светильника и яркость огней города.
- **Детали:** ветер и облачность, транспорт и капли, огни вышек, четыре атмосферные прослойки, сброс и мастерская.

Плотность уменьшена за счёт разделения задач, а не удаления настроек. Обычные подписи выросли до 12–14 px, кнопки имеют удобную область нажатия, ползунки — заметные ручки. Состояния передаются цветом и aria-атрибутами. В каждом разделе прокручивается только содержимое, заголовок и нижняя навигация остаются доступны. Подробные атмосферные регуляторы открываются постепенно.

Меню закрывается по крестику, Escape, повторному нажатию активного раздела или клику вне панели. Автоматическое закрытие по уходу курсора удалено. Escape возвращает фокус к кнопке открытого раздела. Скрытые разделы исключаются из клавиатурной навигации через hidden; сцена не превращается в модальное окно и остаётся интерактивной.

## Проверка

`npm run test:ui` проверяет переключение всех разделов, работу света и послойной дымки, Escape и возврат фокуса, отсутствие ошибок браузера, размещение панели в 1440 × 1000, 390 × 844 и 844 × 390. Снимки: `artifacts/ui-scene.png`, `ui-light.png`, `ui-mobile.png`. Проверка выполнена в локальном Chrome с программным GPU. Аудиопотоки не перепроверялись: их реализация не менялась.

Исходники интерфейса: `src/experience/interface.ts` и `interface.css`. Контролы сохраняют прежние ID, настройки, API и обработчики сцены.
